# Календарь-Абсурд

Конкурсная работа для антихакатона на тему «намеренно невыносимый UX/UI».
Веб-приложение для регистрации одного календарного события за 5 экранов.

## Возможности

- **Экран 1** — ввод даты и времени. Пять полей раскиданы по экрану, разного кегля;
  прямой ввод с клавиатуры запрещён, менять значения можно только кнопками ±1
  (для года и минут дополнительно ±10). При удержании кнопки дольше 500 мс
  включается автоповтор 8 раз в секунду. Значения циклические.
- **Экран 2** — капча 3×3. Нужно отметить изображения с осенью, календарём или
  цифрой 3. Пул: 18 картинок, при перезапуске выбирается заново. Допускается одна ошибка.
- **Экран 3** — мини-игра «Листопад». Ловите падающие иконки: за 20 секунд надо
  поймать 7 календарей 📅. Остальные иконки-отвлекатели (лист, снежинка, тройка, чашка)
  просто мешают.
- **Экран 4** — сохранение. Две кнопки, обе делают одно и то же (сохраняют событие):
  крошечная «Сохранить» в углу и огромная красная «Отменить всё» в центре.
- **Экран 5** — успех. Событие записано в `localStorage` под ключом
  `absurd_calendar_events`.

## Стек

- HTML5, CSS3, JavaScript ES2020+ (vanilla).
- Хранилище: `localStorage` браузера.
- Никаких сетевых запросов, никакого backend, никакой сборки.

## Формат сохранённой записи

```json
{
  "id": "<uuid v4>",
  "createdAt": "<ISO-8601 момента сохранения>",
  "datetime": "<ISO-8601 события>"
}
```

Современные десктопные браузеры (Chrome, Firefox, Safari — актуальные версии).
Минимальное разрешение 1280×720. Мобильная адаптация не поддерживается.
