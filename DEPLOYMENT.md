# Инструкция по развёртыванию на localhost

Приложение полностью статическое и работает в браузере, без backend и сборщиков.
Для локального запуска достаточно поднять любой статический HTTP-сервер поверх
корня репозитория. Использовать `file://` **нежелательно**: некоторые браузеры
блокируют загрузку локальных ассетов при таком открытии.

## Требования

- Любой современный десктопный браузер: Chrome, Firefox или Safari актуальной версии.
- Разрешение экрана не ниже **1280×720**.
- Один из ниже перечисленных инструментов для локального сервера (Python / Node.js /
  PHP / VS Code Live Server — на выбор).

## Шаг 1. Получить исходники

```bash
git clone https://github.com/Nikisin-git/Useless-Autumn-Calendar.git
cd Useless-Autumn-Calendar
```

Обратите внимание: команды `git clone` и `cd` — **две отдельные строки**.
Если склеить их без переноса (`...calendar.gitcd useless-autumn-calendar`),
Git решит, что URL заканчивается на `.gitcd`, и вернёт «Repository not found».
Регистр в имени репозитория — тоже как выше (`Useless-Autumn-Calendar`).

Либо скачать репозиторий архивом со страницы GitHub (кнопка **Code → Download ZIP**)
и распаковать.

## Шаг 2. Запустить локальный HTTP-сервер

Выберите любой из вариантов ниже. Все команды выполняются **из корня репозитория**
(там, где лежит `index.html`).

### Вариант A. Python 3 (обычно уже установлен)

```bash
python3 -m http.server 8000
```

Приложение будет доступно по адресу <http://localhost:8000>.

### Вариант B. Node.js — пакет `http-server`

```bash
npx http-server -p 8000 -c-1 .
```

Флаг `-c-1` отключает кеш и удобен во время разработки.

### Вариант C. Node.js — пакет `serve`

```bash
npx serve -l 8000 .
```

### Вариант D. PHP (если установлен)

```bash
php -S localhost:8000
```

### Вариант E. VS Code + расширение Live Server

1. Установить расширение **Live Server** (Ritwick Dey).
2. Открыть папку проекта в VS Code.
3. ПКМ по `index.html` → **Open with Live Server**.
4. Браузер откроется автоматически, обычно на `http://127.0.0.1:5500`.

## Шаг 3. Открыть в браузере

Перейти по адресу из выбранного варианта (например,
<http://localhost:8000>). Приложение сразу откроется на первом экране —
«Ввод даты и времени».

## Шаг 4. Проверить сохранение события

После полного прохождения всех пяти экранов запись события появится в
`localStorage` под ключом `absurd_calendar_events`. Проверить:

1. Открыть DevTools (**F12** или **Ctrl+Shift+I**).
2. Вкладка **Application** (Chrome) или **Storage** (Firefox).
3. Раздел **Local Storage → http://localhost:8000**.
4. Ключ `absurd_calendar_events` — массив JSON вида:

   ```json
   [
     {
       "id": "b1c2d3e4-...",
       "createdAt": "2026-09-02T12:34:56.789Z",
       "datetime":  "2026-09-05T18:30:00.000Z"
     }
   ]
   ```

## Возможные проблемы

- **Порт 8000 занят.** Укажите другой, например `python3 -m http.server 8080`.
- **Пустые ячейки капчи.** Открыли `index.html` двойным кликом (по `file://`).
  Поднимите статический сервер, как описано выше.
- **Приложение выглядит сломанным.** Проверьте, что ширина окна не меньше
  1280 px. Мобильная адаптация вне области задачи.
- **Событие не появляется в `localStorage`.** Убедитесь, что вы полностью
  прошли до экрана «Событие зарегистрировано!» и что в браузере не отключено
  хранилище для сайта.

## Остановка сервера

Нажмите **Ctrl+C** в терминале, где запущен сервер.
